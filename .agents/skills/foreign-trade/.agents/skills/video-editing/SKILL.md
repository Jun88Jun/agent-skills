# Skill Name: video-editing-pro
## Description
商用短视频剪辑辅助技能，适配PR、达芬奇软件。可完成外贸厨具类短视频**爆款竞品分析、爆款脚本拆解、爆款脚本文案输出**；生成产品短视频脚本、分镜脚本、剪辑节奏规划、字幕文案、BGM推荐、调色方案，同时提供剪辑硬件选型、素材存储、缓存路径配置方案，产出适合Facebook、视频号、亚马逊A+页面的产品短片。
## Trigger Rule
用户提到剪辑、PR、达芬奇、短视频脚本、分镜、产品宣传片、调色、字幕、视频素材存储、剪辑硬件、外贸厨具产品短视频、亚马逊A+视频、**爆款分析、竞品视频拆解、爆款文案、爆款脚本**时，启用本技能。
## Capabilities
1. 外贸厨具短视频爆款分析：抓取同品类海外社媒爆款视频，拆解钩子结构、镜头节奏、文案卖点、转化逻辑，输出爆款复盘报告
2. 对标竞品视频拆解，复刻改编爆款脚本，生成全新原创爆款脚本文案、开篇钩子、字幕卖点文案
3. 外贸厨具产品短视频脚本、分镜、拍摄文案撰写，适配产品展示短片
4. PR/达芬奇剪辑方案、剪辑节奏设计、字幕文案、BGM风格推荐
5. 视频存储硬件方案：CMR垂直硬盘、PSSD选型，硬盘盒、PR/达芬奇缓存路径配置建议
6. 短视频平台适配优化：Facebook短视频、微信视频号产品短片、亚马逊A+视频文案优化
7. 产品视频拍摄思路，光影、釉面/金属反光拍摄提示，突出厨具质感
## Constraints
1. 硬件存储方案仅技术参考，不做采购担保；
2. 视频脚本以商用外贸产品片为主，不生成违规、侵权内容；爆款分析仅做思路参考，不保证一定出爆款；
3. 调色、参数建议以真实产品质感优先，不做脱离实物的夸张美化；
4. 拆解脚本只做参考学习，禁止直接抄袭他人完整视频素材。
